## Оставшиеся ограничения / отдельная работа

- API, dashboard, legacy BatchProcessor, ModelOptimizer/ONNX, parquet data module,
  train_model.py и evaluate_model.py не приведены этим патчем к общему контракту.
  Например, optimizer передаёт старые keyword inputs, а BatchProcessor ожидает
  другой формат batch/result. Не использовать их как доказательство готовой интеграции.
- Online learner остаётся экспериментом; replay ожидает совместимые формы samples,
  отсутствуют drift/rollback/согласованность параллельного serving.
- Cache не ограничен по числу ключей; при внешнем изменении весов требуется
  clear_cache(). По умолчанию cache выключен.
- Полная проверка dtype/device/finiteness и ModelConfig ещё не реализована.
- CUDA, real VK data, устойчивость под нагрузкой и SLA не проверены.
- Зависимости пока не зафиксированы lock-файлом; точная повторяемость окружения
  между датами не гарантирована.
- LICENSE отсутствует, хотя metadata указывает MIT; README теперь это отражает.

`main` не меняется. PR остаётся draft. Успешный CI не разрешает автоматический merge.
